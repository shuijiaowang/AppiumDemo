# 前置条件
## 下载appium本地服务
npm install -g appium   //这是相当于下载了个程序？
appium //本地先启动appium服务器
appium driver install uiautomator2 //安装驱动？
## 下载Android Studio
npm install webdriverio  //node服务器调用的库？

Android Studio :https://developer.android.com/studio?hl=zh-cn //byd用梯子还打不开下载不了、
File → Project Structure->SDK Location ==（例如：C:\Users\你的用户名\AppData\Local\Android\Sdk 或你自定义的路径）
配置环境变量 ANDROID_HOME
   %ANDROID_HOME%\platform-tools（存放 adb 等调试工具）
   %ANDROID_HOME%\tools（存放 sdkmanager 等工具）
   %ANDROID_HOME%\emulator（存放模拟器工具，可选）
验证配置是否成功
   关闭并重新打开命令提示符（Win+R 输入 cmd）
   adb version（检查 adb 工具）
   sdkmanager --version（检查 SDK 管理工具）
新建一个 Android 项目：等待 Gradle 同步完成（首次可能较慢，需要下载依赖）

完全关闭goland/idea，重新加载
### 可视化
### uiautomatorviewer，不好用
setting->AndroidSDK(SDK manager)->SDK Tools ->取消勾选Hide Obsolete Packages ->选中Android SKD Tools(Obsolete) 下载
打开文件加Sdk\tools\bin 双击uiautomatorviewer.bat，成功运行。
需配置jdk1.8，高版本jdk不行。 https://mirrors.huaweicloud.com/java/jdk/8u202-b08/
### Android Studio Layout Inspector
貌似只能连接Android Studio里自己启动的模拟器，只能看自己的软件。
### AppiumDesktop
旧版本，不再维护，不建议使用

### Appium Inspector，√
